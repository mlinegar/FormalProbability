# ML: supervised-learning vocabulary

Lightweight definitions meant to be shared with the other areas.

- `Core`: hypotheses, losses, and population risk.
- `ERM`: empirical risk, empirical risk minimization, and the generalization gap.
- `DecisionTree`: binary decision trees, routing, Gini and entropy impurity,
  cost-complexity pruning, and axis-aligned splits, with a proof that a tree with
  measurable splits defines a measurable predictor (`DecisionTree.measurable_eval`).
